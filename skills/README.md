# Skills - React Template Base

AI agent skills for working with this project. Each skill provides specialized guidance for specific tasks.

## Available Skills

| Skill | Description |
|-------|-------------|
| `commit` | Git commit conventions |
| `pr` | Pull request template and process |
| `typescript` | TypeScript patterns and best practices |
| `react-18` | React 18 hooks, patterns, and performance |
| `vitest` | Testing with Vitest and React Testing Library |
| `components` | Component patterns and structure |
| `hooks` | Custom hooks patterns |
| `modules` | Module structure and organization |
| `naming` | File/folder naming conventions |
| `services` | HTTP services and API patterns |
| `teaching` | Teaching mode - explain WHY behind decisions |
| `skill-creator` | Create new skills |

## Usage

Skills are referenced in `AGENTS.md`. When working on a task, consult the relevant skill for patterns and guidelines.
